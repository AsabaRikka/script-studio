# 创意与提示词实验室使用说明

> 已被用户否定并撤下一源多创；此文仅留历史。当前请看[提示词优化使用说明](./prompt-optimizer-usage.md)，不再按下方旧流程操作。

从顶栏「创意与提示词实验室」进入；竞对列表的「一源多创」也能直接带入对应来源。沿用创作台的模型、思考程度、时长与当前选材范围。

## 同一竞对反复利用

选定一条来源，已使用的来源须明确勾选复用。先点「AI规划角度」，默认最多3条、上限6条；资料不足时允许少给，并显示缺口。查看原稿、来源借用点和我方事实，调整角度、口吻及推进节拍，取消不需要的方向，再点「按所选任务生成」。规划编辑在同一标签页刷新后保留。

每个任务单独生成、保存为新草稿；可直接查看并精修。整批初评、正文近似预警与事实疑点均附理由，不代表已核实游戏录像。来源覆盖列表记录生成方向与当前正文的人工采用情况；普通列表隐藏已使用的规则保持。

## 持续改进提示词

先在结果区或沉浸精修中「评价这篇稿」，选择AI原稿或人工修改稿，记录采用、待修改、弃用和具体原因。反馈绑定正文与编辑版本；修改后重新评价，旧评价保留。旧稿无法恢复的提示词版本显示未知。开发验证反馈另标，不算人工采用。

在「提示词对照」里勾选失败反馈，生成一个局部候选，查看修改、原因与风险。候选不会自动生效。选两个版本与3–6份有来源快照的草稿，开始同条件实验；同源派生稿不能当独立来源证据。来源、选材、创意任务、模型设置、模板及评分规则均冻结。

结果逐例显示A/B正文、证据和胜负；允许相当、都差与不确定。实际渲染提示词相同的样例会跳过，不付费制造无效对照；正文相同则直接判平，不调用AI裁判。事实疑点和换序分歧要求继续核对。小样例筛查不等于已证明普遍提升。

在「版本与回滚」手动采用、停用或恢复版本。当前生效版本需先切换才能停用；历史模板快照和已接受批次不随之后的修改变化。实验输出只有点击「采用为新草稿并精修」才另存，不覆盖原测试稿。

## 调用、停止与恢复

执行前显示模型和调用上限。规划最多1次；每篇生成含最多1次现有内容修复，整批初评1次；双版本每例通常2次生成加1次裁判，可选增加1次左右对调复评。失败请求也计入账本；相同提示词/正文跳过可减少调用。未配置单价，因此不估算金额。

「停止后续调用」等待当前请求结束，再停止之后步骤。页面刷新可从「任务记录」查看；服务中断后标为中断，不自动继续计费，也不自动重发失败请求。重新执行须明确点击新任务。

数据放在本机 `data_cache/quality/`，包括模板快照、生成溯源、审稿反馈、创意规划和任务账本。它们与现有草稿一起备份；不要把含完整参考原稿和渲染提示的本地运行资料公开提交。
