# 提示词优化怎么用

顶部点击「提示词优化」。此前的一源多创已撤下，旧稿仍在草稿箱。

**先写问题。** 选择要改善的写稿方式，写一句具体目标，例如“别再介绍武器，保留母稿节奏，多写玩家当场反应和选择，不编造清场”。如果某一条稿子问题最典型，选择“重点问题样例”并粘贴你的参考改写；参考改写只提取句号节奏、镜头视角和转折方式，不会被当成所有稿件的逐字标准答案。模型、仿写方式、时长及思考程度沿用创作台；需要时再展开运行设置。

**预览，再开始。** 点击「预览测试样例」，系统优先选有人工失败反馈的稿件，并挑选不同来源。默认6篇，分成用于修改、用于筛选、独立验收三组；最后一组不提供给优化器。预览不调用模型。确认后点「开始自动优化」，默认最多试改2轮、所有模型请求总上限64次。金额未配置，调用上限不是金额。

**看结果，再决定。** 每轮展示修订原因、可能退步、新旧文案和被保留/淘汰的理由，并显示感叹号、强程度词、转折和武器说明重复等编辑诊断。编辑质量分和事实安全门分开：风格变好可以帮助GEPA继续搜索，但事实有疑点、证据不足、独立验收退步时不自动采用。模型没有返回有效生成/评审时会明确显示模型服务问题，不再伪装成“提示词没有改进”。

独立验收支持试用时，点击「采用这次修订，旧版保留可回滚」。旧版停用并保留；在下面「历史提示词与回滚」可恢复切回。采用影响后续生成，已有批次与草稿不改写。

日常生成或从草稿箱打开文案后，成稿旁直接点击「评价文案」，勾选问题并写具体原因，保存为采用、待修改或弃用。AI原稿和人工稿分别评价；改稿后旧评价不会套到新正文。下一轮优化优先使用有失败反馈的样例，当前正文的人工评价作为反思资料，不把收藏、保存或旧人工稿自动当正确答案。

## 实际使用了什么开源项目

**GEPA 0.1.4已直接接入。** Python依赖固定在requirements.txt；运行调用 `gepa.optimize`，通过 `StudioAdapter`连接本项目生成与评审。候选反思循环、接纳、验证集选择及Pareto保留由GEPA实际执行。工作室负责提示词可改范围、冻结素材、事实与输出校验、总调用账本和停止控制。

**Promptfoo 0.125.1用于已执行结果的离线矩阵回放。** 运行结束可下载回放包，解压后按README运行，生成HTML。不需要API Key、不再调用模型，也不是另一次独立质量评估；得分来自这次冻结评审。已经用真实CLI验证导出/provider/断言与分数读取。不会把未运行的组合补生成。

不是把Langfuse、DSPy、Opik等一并部署；原始调研的其他项目仍是方法参考或后续备选。源码、固定版本、运行账本和回放包能对应核对。

## 本轮证据与限制

GEPA真实链路试跑使用gemini-3.8-flash、low，用户提供的华容道问题稿经结构化诊断识别为5个感叹号、9个强程度词、0个转折词，并与参考改写的0/0/10做对照。首次隔离运行实际9次调用，候选的风格指标已改善但因事实疑点不能采用；另一次生成规则失败已明确归类为模型未返回有效结果。两次均未改正式提示词。优化、验证与验收分组、完整采用/回滚、失败、停止、中断保护另由真实GEPA加模拟模型测试验证。

少量AI编辑评分不等于已经提升投放效果。后续依据你的具体评价继续改进；用户确认采用之前不替换正式提示词。运行中可以停止后续请求；当前请求完成后停止，服务中断不自动继续计费。历史运行可从本页恢复查看。
