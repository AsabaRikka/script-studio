# 守桥脚本工作室：运行与日常操作

项目用途、核心能力和首次安装步骤见[仓库首页](../README.md)。本目录是实际应用目录，运行 Python 命令前请先进入这里。

## 配置与启动

安装 `requirements.txt`，将 `config.example.json` 复制为 `config.json`，再运行 `python launch_studio.py`。网页地址为 `http://127.0.0.1:8501/`，Windows 也可双击 `run.bat`。

在右上角「模型配置」填写 API 地址、API Key 和模型名称，测试连通后保存。生成与优化使用 OpenAI 兼容服务；请使用服务商实际提供的模型 ID。真实配置仅存本地，不提交 Git。

飞书集成需要配置 Base Token 和表 ID，并登录拥有对应权限的 `lark-cli`。`server.py` 中的 `LARK_CMD` 当前是原开发机路径，迁移电脑时需调整。仓库没有业务缓存，新安装需要另外准备素材与表字段。

## 从素材到成稿

在左侧素材库筛选和勾选范围，再选择创作模式、模型、思考程度和目标时长。可以预览实际提示词，然后单篇或批量生成。玩法与关卡需要明确勾选才注入；纯随机抽样可在候选用尽后进入新一轮复用。

生成后检查全文与分镜，进入「沉浸式精修」修改台词、画面和游戏动作。整篇改写与单镜重生成会提供候选，确认采用后再改当前稿。AI 原稿与人工修改稿分开保留；草稿箱用于继续编辑、回看和管理。

人工全文与分镜不一致时，可按一镜一段换行，再使用「按换行分配」。人工稿不受 AI 生成的时长上限限制；镜头时长仍需按实际制作核对。

## 补充素材库与飞书写入

顶栏「补充素材库」支持 XLSX / CSV、粘贴全文与已有本地文案。先筛选、分析并审核结构、组件和文字分镜，再按需写入三库。只有文字来源时，画面为推断、时间待视频核对。

单条与批量任务保存本地进度；失败项保留原因，可恢复查看。飞书写入前会核对目标与字段，写入后读回。预览、保存本地稿和写入飞书是不同动作；完成远端写入前仍需检查对应回执。

旧「同步飞书」全量同步入口存在失败保护待办，当前请勿使用。素材补库已核验记录的增量缓存更新不代表全量同步。

## 提示词与质量反馈

「提示词设置」支持编辑规则、版本切换和完整预览。保留模板中的 `{{变量名}}` 与 JSON 输出字段；硬性代码校验不会随规则文字修改而取消。默认规则在 `prompt_defaults.json`，本机覆盖保存在不提交 Git 的 `prompt_overrides.json`。

对成稿留下具体的采用、待修改或弃用反馈，再进入「提示词优化」提出目标、预览样例并开始 GEPA 搜索。候选需经过独立来源验收并手动采用，旧版可回滚。详见[使用指南](docs/prompt-optimizer-usage.md)。

## 安全重启与排查

先保存网页，等生成、改写、补库及飞书写入结束，再使用 `重启服务.bat`。只读检查命令为：

```powershell
python launch_studio.py --check-restart --no-browser
```

不要另起第二个 8501 服务。启动器无法判断所有未保存网页内容，重启前仍需人工确认。启动失败可查看本地 `output/runtime/server-8501.log`。

模型失败时先看具体错误，再检查 API 配置与超时；不要盲目重复付费请求。飞书失败时先核对 CLI 登录身份、权限、表配置及字段契约。服务可打开但没有素材时，先确认本机是否准备了 `data_cache/`。

开发与接手按 [AGENTS.md](AGENTS.md) 和 [HANDOFF.md](HANDOFF.md) 进行，已知问题、当前验证结果及待加载代码以交接文档为准。
